Before you start.

Download the EXE from the official SlendyStuffClicker page. It links to the versioned GitHub release, release notes and current download identity. Browser and mobile versions of Cookie Clicker are not supported.

Keep the EXE in a folder you can write to. There is no installer or separate dependency download, but setup adds a companion mod to the game folder and the app stores local pairing settings and bounded logs. Back up your game save using the game’s save options before changing mods.

The current preview is unsigned. Windows may show an unknown-publisher warning or block it; some devices offer no override. Read the Windows notes on the download page. You do not need to disable Windows protection.

1. Find the Cookie Clicker Steam folder.

Open the EXE and choose Set up game. The usual folder is:

C:\Program Files (x86)\Steam\steamapps\common\Cookie Clicker

If Steam is installed on another drive, open the game in your Steam library, then choose Properties → Installed Files → Browse. Use that folder in setup. Select the game folder, rather than Steam’s top-level folder or a shortcut.

2. Add and enable the companion mod.

  1. Choose Add companion mod when setup recognizes the game folder.
  2. In Cookie Clicker, open Options → Manage mods and enable SlendyStuffClicker.
  3. Fully close and restart the game so it loads the new companion.
  4. Keep the clicker open and wait for CONNECTED.

Adding files does not start clicking. Choose Start automation only when you are ready. If you previously used an older companion, fully restart the game after updating it too.

3. Set your click speed and golden-cookie controls.

Use Clicks per second to choose a rate and Stop after clicks to set a run limit. A limit of 0 means unlimited. The visible controls offer up to 1,000 accepted clicks per second when the game’s click cooldown is overridden; actual performance depends on your PC and the game.

Reduce automated click sounds and particles limits effects caused by automation. Collect golden cookies uses the game’s normal golden-cookie objects wherever they appear, including seasonal hearts and cookie-storm reward drops. Wrath cookies are off by default and can be enabled separately in Gameplay. Main clicks, golden collection and shop buying can run independently within the active automation session.

Watch Live status for connection state, clicks this run and purchase totals. Start with a modest rate, then adjust it while watching how the game responds.

4. Choose buildings and upgrades for auto-buy.

Open Auto-buy settings. Select the buildings and supported upgrade groups you want it to consider. Enter Cookies to keep in reserve if you want to preserve part of your balance, then save the settings.

Enable auto-buy on the main screen when ready; it is off by default. While automation runs, it uses your chosen production-payoff or cheapest-first strategy, one purchase at a time. Open Gameplay to set building targets, caps, priorities and production-based reserves. It pauses in Sell mode and skips protected or unsupported purchases, including sugar-lump purchases and confirmations.

Wrinklers, seasonal events and achievements.

Open the Gameplay, seasons & Completionist window. Use the grouped sidebar to open Controls, Wrinklers, Shop, Seasons, Completionist, minigames and session tools. Each page uses checkboxes, fixed choices and labeled numbers. Choose Save settings to apply changes without closing the window.

For simple wrinkler payouts, choose Wrinklers → Use simple payout settings → Save settings. This waits for attachment, stored cookies and 60 seconds of observed feeding. The status table explains why a wrinkler is waiting. Shiny wrinklers stay protected.

Seasons shows event availability and missing collection items. Completionist lets you search unearned goals, view their requirements, pin a target and open filters when needed. Choose Suggest only for guidance or Assist with enabled controls for simple assistance.

Combos optionally waits for Frenzy, with or without a building bonus, before casting Force the Hand of Fate. Set mana, time and backfire limits. Godzamok sales need a separate opt-in and per-run limits; they remove buildings and do not repurchase them. Spell outcomes remain random.

Use the minigame pages for optional lump harvesting, missing-seed harvesting, spell assistance and budgeted stock trades. Review destructive actions individually in Game tools. In Maintenance, optionally schedule verified save-and-restart cycles and keep private save backups. New automation is off until enabled.

5. Minimize the game and keep your mouse free.

After the companion connects and clicking starts, you can minimize Cookie Clicker and use your mouse in another app or game. SlendyStuffClicker sends actions inside the supported game instead of moving the system cursor or generating ordinary mouse clicks.

The game and clicker must remain running. A closed or suspended game cannot accept actions. If the computer sleeps or the connection is lost, check the connection and status before starting again. Global shortcuts are optional; leave them off if you want to avoid keyboard conflicts in another game.

If the companion does not connect.

The setup folder is not recognized.
Use Steam’s Installed Files → Browse option again and select that game folder. Another Steam library may be on a different drive.
The app says it is waiting for the game.
Check that the companion is enabled in Manage mods and that you fully restarted the game after adding it. Keep both the game and clicker open.
Clicking stopped during a session.
Read Live status before restarting. A run limit, lost connection or resource guard can stop automation. If memory has grown, save and fully restart both apps instead of repeatedly pressing Start.
The game or mod changed after an update.
Check the versioned release notes and use Check for updates. Send the version, what you were doing and the visible status through website feedback. Leave out passwords, saves and personal details.

Updates and running notes

* Save and fully restart the game and clicker at least every 12 hours, or sooner if memory grows or performance slows. Restarting only the clicker does not release the game’s memory. Resource guards reduce risk, but the preview does not guarantee unattended or overnight stability.

Save & restart game pauses automation, checks a local save by reading it back, reopens through Steam and resumes a previously running session after the fresh companion connects. If a stage fails, clicking stays stopped. An optional schedule and private save backups are available in Gameplay → Maintenance.

Use Check for updates to compare the app’s internal version with GitHub releases. In v0.5.2.7 and later, review the notes and choose Update this copy to approve replacing the EXE. The previous EXE is kept for recovery, profiles remain local and the app restarts stopped. For v0.5.2.5 or earlier, download v0.5.2.8 and replace the old EXE manually first. Save your game, update the companion and fully restart the game afterward.
