GETTING STARTED

Download. Pair. Play.

For Cookie Clicker on Steam and Windows 10/11, 64-bit. Browser and mobile versions are not supported. SlendyStuffClicker is an independent SlendyStuff tool, not affiliated with or endorsed by Cookie Clicker’s developers.

It is portable: there is no installer. First-time setup writes the companion mod into your game folder, and the app stores local pairing settings and bounded diagnostic logs.

  1. Open the EXE.

    Keep it in a folder you can write to. No extra download files are needed.

  2. Choose Set up game.

    Steam libraries are detected. The usual library is C:\Program Files (x86)\Steam\steamapps\common. Select the Cookie Clicker folder inside it, or find your folder through Steam → Properties → Installed Files → Browse.

  3. Enable the companion.

    Open Options → Manage mods in the game, enable SlendyStuffClicker and restart the game. Wait for CONNECTED, then choose Start automation.

* Windows trust: This preview EXE is unsigned. Windows may show an unknown-publisher warning or block it. Check that it came from this page or its linked GitHub release before running it. You do not need to disable Windows protection. If Windows offers More info → Run anyway, that choice allows the app to run. Some devices do not offer that option. A warning is not a guarantee that a file is safe.
* Long sessions: Long game sessions can increase memory usage. Save and fully restart both the clicker and the game at least every 12 hours, or sooner if memory grows or performance slows. Restarting only the clicker does not release the game’s memory. Save & restart game resumes a previously running session after the fresh companion reconnects. If saving, closing, opening or reconnecting fails, clicking stays stopped. You can then close and reopen the clicker yourself. Resource guards reduce risk; 12 hours is maintenance guidance, not a guarantee of unattended stability.

    BEFORE YOU DOWNLOAD

    Cookie Clicker auto clicker questions.

    Is this Cookie Clicker auto clicker free?

    Yes. SlendyStuffClicker is free to download, use and share. The current release is v0.5.3.1, a growing public preview.

    Is it a Cookie Clicker mod or a Windows app?

    Both work together. You download one Windows EXE. Set up game adds the companion mod to your Steam game folder; enable it in Manage mods and fully restart the game to connect.

    Can it click while minimized and leave my mouse free?

    Yes, while Cookie Clicker is running and connected. Actions happen inside the game rather than through system mouse input. You can use your mouse elsewhere, including another game. A closed or suspended game cannot accept clicks.

    Does it work with the browser or mobile version?

    No. This release supports the Steam edition of Cookie Clicker on 64-bit Windows 10 and Windows 11.

    Can it collect golden cookies and buy upgrades?

    Choose independent main clicks, normal golden collection and auto-buy. Wrath cookies and reindeer have separate optional controls. Smart shop settings include targets, caps, priorities and reserves. Auto-buy is off by default.

    How fast does the auto clicker run?

    The controls offer up to 1,000 accepted clicks per second by overriding the game’s click cooldown. Actual performance depends on the game and your PC. Resource guards can stop automation, and higher rates add work for the game.

    Does the EXE need installing, and why might Windows warn me?

    There is no installer. Companion setup writes a mod into the game folder, and the app keeps local pairing settings and bounded logs. The preview EXE is unsigned, so Windows may warn or block it. Read the Windows notes above before running it.

    Can I leave it running overnight?

    Long sessions can increase game memory use. Save and fully restart the game and clicker at least every 12 hours, or sooner if memory grows or performance slows. Resource checks reduce risk but cannot guarantee an unattended session will stay stable.
