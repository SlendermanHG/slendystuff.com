GETTING STARTED

Download. Pair. Play.

For Windows 10/11, 64-bit, and the supported Steam cookie-building idle game. Browser and mobile versions are not supported. This is an independent SlendyStuff tool.

It is portable: there is no installer. First-time setup writes the companion mod into your game folder, and the app stores local pairing settings and bounded diagnostic logs.

  1. Open the EXE.

    Keep it in a folder you can write to. No extra download files are needed.

  2. Choose Set up game.

    Steam libraries are detected. The usual library is C:\Program Files (x86)\Steam\steamapps\common. Select the supported game’s folder inside it, or find your folder through Steam → Properties → Installed Files → Browse.

  3. Enable the companion.

    Open Options → Manage mods in the game, enable SlendyStuffClicker and restart the game. Wait for CONNECTED, then choose Start clicking.

Windows may ask about trust.

This preview EXE is unsigned. Windows may show an unknown-publisher warning or block it. Check that it came from this page or its linked GitHub release before running it. You do not need to disable Windows protection.

If Windows offers More info → Run anyway, that choice allows the app to run. Some devices do not offer that option. A warning is not a guarantee that a file is safe.

Restart after six hours.

Long game sessions can increase memory usage. Save and fully restart both the clicker and the game at least every six hours. Restarting only the clicker does not release the game’s memory.

Save & restart game resumes a previously running session after the fresh companion reconnects. If saving, closing, opening or reconnecting fails, clicking stays stopped. You can then close and reopen the clicker yourself.
