# SlendyStuffClicker release reference

SlendyStuffClicker is distributed as one portable Windows EXE. Tags match the app’s four-part internal version.

- [v0.5.1.0 release notes](releases/0.5.1.0/RELEASE-NOTES.md)

[Current download and setup](https://slendystuff.com/slendystuffclicker/) · [Versioned releases](https://github.com/SlendermanHG/slendystuff.com/releases)

The website checks the release asset’s name, URL, size and SHA-256 against its product metadata before enabling a download. Repository publication fragments reconstruct the EXE; users need only the single release download.

Updates are manual. The app checks public release metadata and opens the matching release page. It does not install downloaded code automatically.

* Preview EXEs are unsigned. A checksum identifies file bytes but does not establish publisher trust. Windows may warn or block the download.
