# SlendyStuffClicker v0.5.2.0

A SlendyStuff Production · Free to use and share · One portable Windows EXE

A free auto clicker and companion mod for Cookie Clicker on Steam. Actions happen inside the game, leaving the system mouse free.

## What's new

- **Independent controls:** run main-cookie clicks, golden-cookie collection and shop buying separately.
- **Seasonal collection:** collect golden hearts and cookie-storm rewards wherever they appear. Wrath cookies and Christmas reindeer have separate optional controls.
- **Smarter buying:** choose estimated production payoff or cheapest first, set building targets, caps and priorities, and preserve fixed or production-based reserves. Lucky reserves and bonus protection are optional.
- **Wrinkler rules:** pop by stored-cookie threshold, feeding time or keep count. Automatic payouts wait for attachment and stored cookies; shiny wrinklers remain protected. Dedicated status explains waits and payout requests.
- **Seasonal planning:** track recurring events, missing drops and purchases, upcoming dates, current-run collections and earned achievements. Review native Season Switcher prices before confirming a switch.
- **Completionist guidance:** browse supported goals, filters and shadows, pin a target or exclude it, and see progress, estimated costs and uncertain timing. Suggest only gives guidance; assistance uses enabled controls and selected shop items.
- **Challenge protection:** conflicting actions are held for Neverclick, True Neverclick, Hardcore, Four-leaf cookie and Eldeer. Broken conditions are identified for the current run. Achievements use normal game actions.
- **Focused settings and profiles:** fixed-choice lists and labeled numeric fields, searchable goal details, local profiles, bonus timers and bounded activity history.
- **Reliability improvements:** wrinkler decisions run before heavy click batches; low-speed collectors remain responsive; goal protections update before the next action; special-action confirmations expire.

## Set up this update

Download **SlendyStuffClicker.exe**. Run **Set up game**, fully restart Cookie Clicker and enable SlendyStuffClicker in **Options → Manage mods**. The updated companion is required.

Main clicking and normal golden collection are selected by default. Auto-buy, wrath cookies, reindeer, wrinkler popping and Completionist assistance are optional. For simple wrinkler payouts, choose **Wrinklers → Use simple payout settings → Save settings**; the rule waits for attachment, stored cookies and 60 seconds of observed feeding.

Choose up to 1,000 accepted clicks per second with the cooldown override. Actual speed depends on the game and computer. Automation starts when selected and stops on invalid or expired commands, lost connection or a resource safety stop.

There is no installer. Setup adds the companion to the game folder; pairing settings, profiles and bounded logs stay locally. **Website feedback** opens the official feedback page without uploading logs. Updates are manual: review the notes, download the new EXE, close the clicker and replace its copy. Back up the game save before changing mods.

## Running notes

* Supports Cookie Clicker Steam version 2.053 on 64-bit Windows. Other game versions stop automation until compatibility is reviewed. Browser/mobile editions are not supported. SlendyStuffClicker is independent of the game developers.

* This preview is unsigned. Windows may warn or block it, and some devices offer no override. Keep Windows protection enabled and verify the official source. SHA-256 identifies the file bytes; it does not establish publisher identity or provide executable signing.

* Plan to save and fully restart both the game and clicker at least every 12 hours, or sooner if memory grows or performance slows. Restarting the clicker alone does not release game memory. This EXE contains the earlier six-hour reminder. Resource checks reduce risk but do not guarantee unattended stability.

* Local automated checks cover supported rules, resource stops, connection validation, privacy filtering and simulated save/restart failures. Full live Steam restart behavior, Steam achievement delivery and representative long-session reliability are not certified by those checks.

Advanced minigame automation and additional progression tools are in development.
