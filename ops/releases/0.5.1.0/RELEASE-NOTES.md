# SlendyStuffClicker v0.5.1.0

Free portable Windows preview from SlendyStuff. One EXE, no installer. Sends actions inside the supported Steam cookie-building idle game, leaving your mouse free for other apps and games.

## Included in this preview

- Refreshed SlendyStuff and SlenderFox branding, app icon, website link and visible v0.5.1.0 version.
- Background clicking with configurable speed and a click limit. Automation starts only when you choose Start clicking.
- Auto-buy options for selected buildings and upgrades.
- Optional golden-cookie collection while clicking, wherever they appear. Wrath cookies and other special objects are excluded.
- Clicks this run and purchase totals in Live status.
- Save & restart game: pauses clicking, checks the saved data by reading it back, reopens through Steam and resumes after reconnecting. Failed or cancelled restarts leave clicking stopped.
- Memory and resource safeguards that stop automation when limits are exceeded, plus a six-hour restart reminder. Save and fully restart both the clicker and the game after long sessions; restarting only the clicker does not release game memory.
- Check for updates compares the app's internal version with public GitHub releases. Updates are manual: review the notes, download the new EXE, close the clicker and replace your old copy.

## Getting started

Download **SlendyStuffClicker.exe** below. Open it, choose **Set up game**, enable the SlendyStuffClicker companion in the game's mod settings, then fully restart the game. Wait for CONNECTED before starting. Existing users must restart the game once to load the updated companion.

Setup writes the companion mod to the chosen game folder and stores local pairing/settings and bounded logs. No separate download files are required.

## Current limitations

- This EXE is **unsigned**. Windows may warn or block it; some devices offer no individual override. Do not disable Windows protection. A warning or the absence of a warning does not prove a file is safe.
- The app's **Website feedback** button opens the feedback section at slendystuff.com without sending logs. Direct diagnostic sending is withheld until Cloudflare delivery is verified. Website feedback submission is enabled only when its protected service is available.
- Isolated checks passed for the app, privacy filtering, resource guards, golden-cookie handling, restart/save failure cases and public startup. A full live Steam restart cycle and overnight stability have not yet been verified. The precise cause of the previous long-session memory growth remains unconfirmed.
- Trusted code signing, tamper resistance and automatic update installation remain unfinished. SHA-256 identifies this download; it does not prove publisher identity or make an unsigned EXE tamper-proof.
