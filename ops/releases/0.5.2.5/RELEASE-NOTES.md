# SlendyStuffClicker v0.5.2.5

A SlendyStuff Production · Windows preview · One portable Windows EXE

This preview adds more ways to manage progression, profiles and game sessions.

## What's new

- Compact running notes: 12-hour restart guidance appears as a readable asterisk disclaimer. Windows trust and other relevant limits remain available without competing with the main features.
- Cleaner native windows: the Wrinklers enable checkbox stays within its column. Status counters sit above the readable activity view; live refreshes preserve scroll position. Wrinkler rows and game-inventory text preserve the reader's position too.
- In-game wrinkler countdowns: an optional label follows each native wrinkler. Approaching wrinklers show their feeding allowance; the countdown starts once attachment and stored cookies are observed. Protected shinies, keep rules and minimum stores remain distinct.
- Pet progression: focus on fully training the dragon, optionally allow building sacrifices, collect its four native petting drops, and maximize Santa during Christmas. Auto-buy for training respects selected building types, caps and reserves. Native chances and time windows remain unchanged.
- Seasonal continuity: collectors and countdowns follow native object identities and positions, so hearts, eggs, Christmas skins and Business Day appearances do not need screen matching. Ordinary wrath cookies still need their own permission.
- Ascension assistant: optionally ascend once minimum new prestige and affordable new heavenly purchases are available. A local save is checked by disk read-back first. Normal feeding wrinklers can be collected before the reset; shiny payouts stay protected. Optional heavenly purchases use dependency-aware, bounded best-fit chip spending. Optional reincarnation returns to normal play. Prompts, bonuses, active achievement goals, expired connections and failed saves hold actions.
- Default profiles and auto-start: choose a saved default profile and opt in to starting after its companion connects. Auto-start is unavailable without a saved default, attempts once per app launch and never resumes after Stop or a safety failure. Missing or damaged profiles stay stopped.
- Startup release check: the app checks public GitHub release metadata when opened and shows whether an update is available, it is current or it is a newer local development build. Downloads and replacement remain manual.
- Easier Completionist browsing: search the full installed catalog before paging, optionally show earned achievements, and read native requirements alongside supported action guidance. Earned goals never become assisted targets; unknown requirements remain for manual review.
- Open Cookie Clicker: a verified current companion changes Set up game to Open Cookie Clicker. Update companion remains available. Opening uses the fixed Steam app address and avoids relaunching an already running game.

## Setup for this update

Run Set up game or Update companion, then fully restart the game and enable SlendyStuffClicker in Options → Manage mods. Back up the game save before enabling optional sacrifice or ascension settings.

* Plan to save and fully restart both the game and clicker at least every 12 hours; restart sooner if memory grows or performance slows. Restarting the clicker alone does not release game memory. Resource guards reduce risk; the interval is maintenance guidance, not a guarantee of unattended stability.

* Dragon training can spend cookies and sacrifice buildings. Ascension resets the current run, including cookies, buildings and uncollected wrinkler stores. Enable these options only when you accept those effects. Heavenly spending is a bounded best-fit plan, not a guarantee of mathematically optimal spending or production; choice upgrades require manual setup.

* This is an unsigned Windows preview for Steam game version 2.053. Other versions stop automation. Local scenario checks do not certify Steam achievement delivery or representative overnight stability. No personal game data is uploaded automatically.
